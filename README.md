# OpenCV Image Viewer

## Description
This is a beginner Python project using OpenCV.

The program reads an image from the local computer and displays it using the OpenCV library.

## Technologies Used
- Python
- OpenCV (cv2)

## Features
- Reads an image from a folder
- Displays the image in a new window
- Beginner Computer Vision project

## How to Run

```bash
pip install opencv-python
python image_viewer.py
```
